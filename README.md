## Gerenciamento de veículos

Aplicação de console em C# com foco no gerenciamento básico de um estacionamento.

## Funcionalidades

- Cadastrar veículos
- Listar veículos cadastrados
- Remover veículos
- Realizar calculo do valor a pagar com base no tempo de permanência.

C# | .NET 10.0
